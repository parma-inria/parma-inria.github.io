# Materiali della migrazione

Questa cartella documenta la provenienza dei materiali importati dal [sito Inria di ParMA](https://team.inria.fr/parma/) l'8 ottobre 2026.

- `assets.json`: origine della fotografia e del logo utilizzati nel sito.
- `seminar-original.json`: copia strutturata del programma al momento della migrazione, conservata come riferimento storico.

Questi file **non generano le pagine**. Per aggiornare il programma usa `content/seminar.html`; per cambiare le immagini usa `assets/images/`.

I materiali originali mantengono le loro condizioni d'uso. La migrazione non assegna una nuova licenza a testi scientifici, fotografie o logo.
